# T1K23 Farewell - Thanh Xuân Rực Rỡ 🎓✨

Chào mừng đến với dự án **Kỷ Niệm T1K23**. Đây là một trang web tương tác đặc biệt được xây dựng để tri ân và lưu giữ những kỷ niệm đẹp nhất của tập thể lớp T1K23 trong 3 năm cấp 3 (1000 days).

## Tính Năng Nổi Bật 🚀

Trang web không chỉ là một album ảnh mà còn được thiết kế dưới dạng một hành trình với các minigame và hiệu ứng 3D đẹp mắt:

1. **Game 1: Giơ ngón tay xuống (Never Have I Ever)** ☝️
   - Trò chơi tương tác liệt kê 15 câu hỏi/kỷ niệm tuổi học trò.
   - Hỗ trợ tiến và lùi câu hỏi mượt mà bằng phím mũi tên hoặc click chuột.
   - Hiệu ứng ảnh trôi nổi 3D làm nền siêu đẹp.

2. **Game 2: Đoán tên nhận quà** 🎁
   - Trò chơi hiển thị "Biệt danh" đặc trưng của từng thành viên.
   - Người chơi phải đoán đúng tên của thành viên đó.
   - Trả lời đúng sẽ kích hoạt hiệu ứng "Hào quang" (Fountain effect) siêu mượt bung toả những tấm ảnh đáng nhớ của thành viên đó.

3. **Góc Nhận Quà (Gift Zone)** 💌
   - Nhập đúng sinh nhật (hoặc ID) để nhận lời chúc riêng biệt từ Kmin.
   - **Easter Egg đặc biệt**: Dành riêng cho Ánh Ngọc (sinh ngày 29/03). Nếu nhập đúng mã PIN Netflix bí mật, giao diện sẽ kích hoạt màn biến hình Romantic Pink siêu ngọt ngào.

4. **Chia tay Đỗ Khôi** ✈️
   - Chuyên mục đặc biệt gửi gắm 118 lời chúc, dặn dò đầy yêu thương dành cho Đỗ Khôi trước khi lên đường sang Mỹ.

5. **Trình phát nhạc Thanh Xuân (BGM)** 🎵
   - Tích hợp 20 bài hát thanh xuân bất hủ.
   - Cơ chế random nhạc nền mang lại cảm giác hoài niệm và bất ngờ cho mỗi lần truy cập.

## Công Nghệ Sử Dụng 💻
- **Frontend**: HTML5, CSS3, Vanilla JavaScript.
- **Hiệu ứng**: CSS Animations (Keyframes, Transitions), 3D Transforms, Canvas Confetti.
- **Data Management**: Logic quản lý dữ liệu JSON trong file `.js`.

## Cách Chạy (Local) 🛠️
1. Clone repository này về máy.
2. Mở bằng Visual Studio Code.
3. Cài đặt extension **Live Server**.
4. Chuột phải vào file `index.html` và chọn **"Open with Live Server"**.
